# Tableau de bord académique – PHP

Ce projet a été réalisé dans le cadre d'un TP de PHP à l'EMSI. L'objectif est de créer un tableau de bord académique dynamique permettant d'afficher les informations d'un étudiant, ses notes ainsi que les statistiques d'une classe.

## Fonctionnalités

- Affichage de la fiche étudiant et de sa mention selon sa moyenne.
- Génération aléatoire des notes par module.
- Affichage des appréciations avec un code couleur.
- Calcul des statistiques de la classe : moyenne, minimum, maximum et nombre d'étudiants validés ou ajournés.
- Simulation d'actions administratives à l'aide d'un `switch`.
